## Why

真实模型已经可以初步生成小红书风格文案，但目前缺少一组来自真实育儿经历的稳定基线，无法判断模型输出是否保留事实、符合风格、具备安全边界以及是否值得用户直接使用。现在先建立评测基线，可以在强化事实和医疗安全检查前明确当前 Agent 的真实失败模式。

## What Changes

- 建立 5 个脱敏真实育儿经历案例，覆盖医疗经历、软文广告、潜在睡眠安全风险、轻科普和生活记录。
- 为每个案例记录必须保留的事实、未知事实、禁止推断、期望行为和表达形式。
- 建立人工评分表，评估事实保真、内容安全、风格符合度、结构完整度、自然程度和人工修改成本。
- 为事实阻断、安全阻断和需要人工大改建立硬失败标签。
- 对每个案例运行至少两次当前真实模型，保存输入、模型版本、输出、Agent trace 摘要、评分和人工修改记录。
- 本变更不修改 Agent 的 prompt、工具、事实检查或医疗安全规则；先产出基线和改进依据。

## Capabilities

### New Capabilities

- `agent-evaluation`: 管理真实案例评测集、人工评分标准和可重复的 Agent 基线运行记录。

### Modified Capabilities

无。

## Impact

- 新增评测案例、评分标准和基线记录文档或测试数据。
- 需要记录当前真实模型的模型标识、运行时间、调用结果和必要的 Agent trace 摘要，但不得保存密钥或未脱敏的儿童隐私素材。
- 后续事实和医疗安全检查的变更将以本基线作为回归比较依据。
